# wiring.json / wiring-plan.js / wiring-dialect.js / wiring-generate.js — ONE MANIFEST PER HARNESS, ONE ENGINE
🔴 **MEASURED IN PRODUCTION 2026-08-22.** The harness wiring declared this framework **19 times by hand** (16 gate frames + session gate + turn counter + PreCompact reset). The lane argument was written on the 16 and forgotten on the 3: the gate recorded its deliveries in the daemon's RAM while those peers read and erased the state FILES — TWO MEMORIES. After a compaction the reset wiped a disk the daemon never read, so skills and `once` documents never came back: no error, no badge, nothing red. The doctor caught it, at the NEXT session start, hours later.
📐 **THE CLASS IS STRUCTURAL, NOT HUMAN**: one truth (the lane, the frame count) held in 19 hand-edited copies. Detection after the fact grows linearly with every consumer, harness and machine; so the hand-written copy is REMOVED — `wiring.json` is the source, the declarations are a GENERATED artefact, and divergence stops being possible instead of being caught.
🛑 **TWO MODES, AND ONLY ONE TOUCHES THE OPERATOR'S FILE (the generator WRITES since 2026-08-22 — the read-only phase is OVER).** `--out <file>` emits a FRAGMENT and REFUSES a file named `settings.json`; that is the mode `test/wiring-drift-gate.test.js` uses, where a mistake costs nobody their configuration. `--write <settings.json>` SPLICES the declarations into a real wiring — it exists because the alternative is the hand-editing that produced the 2026-08-22 defect, it is NEVER the default, and it runs only when a human types the flag with no agent running. The two flags are EXCLUSIVE: emitting a fragment and modifying a wiring are two different acts, typed separately on purpose.
🛑 **THE FOUR GUARDS ON THE WRITE PATH, NONE OPTIONAL** — remove one and this tool becomes the fastest way to destroy a machine's whole hook configuration: ① a TIMESTAMPED BACKUP first, its path PRINTED (**a rollback nobody can name does not exist**) ② atomic write (tmp + rename), then RE-READ and PARSED — a broken `settings.json` kills EVERY hook on the machine, ours and theirs, silently ③ the re-read must match what we intended BYTE FOR BYTE, else the backup is RESTORED and the tool refuses (**a half-written wiring is worse than none**) ④ any declaration MENTIONING this framework without being ours by command is a REFUSAL, not a survivor — it would run beside what we wrote, i.e. two wirings of one framework. ⚠️ **IDEMPOTENT by a property of the splice, never by the caller's discipline**: replaying converges on the same file and stacks nothing.
🛑 **`settings.json` IS NOT OURS.** It also carries the operator's own hooks (an MCP sync, a protocol injector, a dead-man check, a launcher guard, a mode capturer), their permissions and their preferences. **The manifest owns ONLY what it declares** — the comparison is per `(event, matcher)` block and ignores every foreign declaration. A generator that rewrote the whole file would destroy configuration it does not own.
🛑 **THE LANE IS AN ARGUMENT, NEVER AN AMBIENT SETTING** — env vars are INHERITED, so a lane in the environment leaks into every child. `stateLane` is declared ONCE in the manifest and applied in ONE pass to the consumer set DERIVED from `clientLane(` in `src/hooks/`; it is spelled by `LANE_FLAG` in `src/client-core.js`, never re-typed. That is what makes "written on 16, forgotten on 3" unbuildable.
🛑 **THE TRANSPORT IS DECLARED, AND A DECLARATION IS KNOWN BY ITS COORDINATES.** `transport` says what carries the GATE's frames: `kind: "command"` (default when the key is absent — the spawn form, and the only one Codex has a handler for) or `kind: "http"` + `host`/`port`/`path` (a local POST to the daemon, the live Claude Code wiring since 2026-08-22). 🔴 Until that key existed the generator could ONLY produce `command` while the machine ran `http`: it could not write the configuration that actually runs, so the whole chain was INERT exactly where it was meant to serve. **An unknown `kind` is a NAMED REFUSAL**, never a quiet fall back to a spawn — a harness with no handler for a transport runs NOTHING, with no error and no log. ⚠️ On `http` the gate carries NO lane argument (the daemon IS the authority) and NO `args` (a URL has no argv — declared arguments would be silently dropped, so they are refused).
🛑 **THE FRAME COORDINATES ARE ONE FACT, TWO WRITINGS**: `--frame k --frames N` in argv, `?frame=k&frames=N` in a query. `wiring-plan.js` computes the pair ONCE and each transport only RENDERS it; ONE reader (`frameCoordinates`) reads it back, so a transport cannot gain a check the other silently lacks. ⇒ **every consumer recognises a gate declaration by its COORDINATES — never by a `command` field, never by a file name** (a URL names a port, not a directory). A judge reading `d.command` alone counted ZERO frames the day the wiring moved to http: loud, and judging nothing. Same authority as `doctor.js`. ⚠️ KNOWN LIMIT, written not hidden: two copies of the framework pointed at the SAME endpoint are indistinguishable to the splice's ownership test — what separates them is the port, and the port is the operator's.
⚠️ **BOTH TRANSPORTS TAKE THE BOUND FROM THE MANIFEST** — a framed consumer may not declare its own `timeout` (two places for one number), and `plan()` writes `bounds.gateHookTimeoutSeconds` on the spawn frames exactly as on the http ones, in the SAME pass. ✅ THE SENTENCE THAT STOOD HERE — *no manifest generates the Codex wiring, closing it means giving Codex a manifest of its own, never patching the generator* — IS HALF TRUE AND HALF STALE SINCE 2026-08-23, and it is rewritten rather than stacked. The MECHANISM is built and a manifest of its own is now all it takes; what is NOT shipped is the Codex manifest itself, and the reason is measured below.
⚠️ **A BOUND HAS TWO ENDS, AND THE STATUS LINE IS DECLARABLE (2026-08-22).** `bounds.gateHookTimeoutSeconds` is refused outside `1..N` where **N is DERIVED** from the smallest numeric handler default of `HOOK_TIMEOUT_DEFAULTS` (`src/harness-profile.js`, 60 s today): beyond what the harness applies on its own a declared bound never fires first, so `999999` used to read as a decision and bound nothing. Measured 2026-08-22: a frame answers in 11 ms, production declares 10 s (~900x). `transport.statusMessage` is now DECLARED; absent, the default stays the DERIVED last segment of the repository root — and on the spawn lane it is written ONLY when declared, because those declarations have never carried one and deriving a default there would rewrite every generated command wiring.
🛑 **`kind: "http"` WITH `stateLane: "files"` IS A NAMED REFUSAL** — the frames would record their deliveries in the daemon's RAM while their peers read and erase the state files: the 2026-08-22 split brain, generated on purpose. A shared state migrates for ALL its consumers or for NONE. Both controls are asserted (the file lane on the spawn transport, and the live pair) so the refusal bites on the PAIR and on nothing else.
🛑 **DERIVE, NEVER ENUMERATE**: `frames` comes from `ctxroute-config.json` (re-declaring it in the manifest would be the two-places-for-one-number divergence of 2026-08-05), the state consumers from the source, the repository root from the LIVE wiring — this repository is public, so an absolute home path may not live in a tracked file. Module paths are repo-relative POSIX; anything else is a named refusal.
🛑 **IT DOES NOT REPLACE `doctor.js --settings` — the two are DEFENCE IN DEPTH.** This gate PREVENTS (the live wiring is exactly what the manifest generates, so a hand edit is red before it is executed); the doctor CATCHES (coordinates, lane coherence and dead paths on whatever is really there, including declarations the manifest does not own, at session start on a machine no test reaches). Deleting either leaves a whole failure mode uncovered.
⚠️ **FAIL-CLOSED AND NON-VACUOUS**, because a mis-parsed comparison looks exactly like a coherent one: unreadable settings.json, invalid JSON, no `hooks` section, zero or several framework roots, an empty manifest, fewer than two declarations on either side ⇒ RED. "We could not measure" is never "it agrees". A machine with no wiring at all SKIPS, visibly, and a skip is not a pass.
⚠️ **SEEN RED, EACH SABOTAGE RUN**: `stateLane: "files"` in the manifest · `--client` stripped from `ctxroute-reset.js` alone in a copy of the live file (the 2026-08-22 defect verbatim) · one frame declaration deleted · an empty `consumers` list (named refusal, exit 2) · unreadable / invalid / hookless / foreign-root settings · `transport.kind: "grpc"` (named refusal, with the `command` control still generating) · an http gate with no declared bound · the http transport paired with the file lane (named refusal, with the coherent pair still generating).
🛑 **`splice()` IS THE ONE DECISION THAT CAN DESTROY THE OPERATOR'S CONFIGURATION** (`wiring-plan-splice.test.js`): everything it calls OURS is REMOVED from a file we do not own, and that file is the only copy. A wrong `true` is not a missing injection, it is a deleted hook ⇒ every cell asserts BOTH sides (ours gone, theirs intact) and the refusal MESSAGES are contract too. ⚠️ Its expectations are written out BY HAND, never read back from the module: an assertion quoting the module under test is mutated with it and stops seeing the mutant.
🛑 **REACH `wiring-plan.js` BY A STATIC ESM IMPORT, NEVER `createRequire` — MEASURED 2026-08-22.** Stryker resolves the tests covering a mutant through the ESM module graph and a `createRequire` edge is INVISIBLE to it: reached that way, the module reported *"No tests were found"* — **601 mutants, ZERO test executed**, on a file listed in `mutate` and therefore believed covered.
⚠️ **DETERMINISM IS A CONTRACT** (same manifest + same machine facts ⇒ byte-identical output; the derived consumer set is SORTED): a drift gate built on a generator that disagrees with itself reports divergences that are not there. Argument order is `lane · manifest args · frame coordinates`, and paths are POSIX on both sides — a command line is executed as written, so `C:\…` and `C:/…` are two spellings and the operator should see that once.
🎯 **ONE MANIFEST PER HARNESS, ONE PLAN ENGINE BEHIND (2026-08-23).** Until then `wiring-plan.js` could produce ONE SHAPE — JSON, one address, `hooks[event][].hooks[]` — so every other harness was still wired BY HAND, i.e. still exposed to the very class the manifest removes. What VARIES is now DECLARED in `harness` (`format` · `events` · `layout` · `write`) and rendered by `src/wiring-dialect.js`; what DECIDES (frame coordinates, state lane, bound, ownership) stays SHARED in `wiring-plan.js`. 🛑 **NO HARNESS NAME MAY APPEAR IN EITHER MODULE'S LOGIC** — a generator that learns one special case per product is a TOOL, and the founding rule is that the engine must not move when a need appears. Sealed by a DERIVED gate (the forbidden literals are read from the manifests themselves, comments stripped so prose stays free to name a harness).
🛑 **THE PROOF IS A FICTIONAL THIRD HARNESS, NOT THE SECOND ONE** (`test/fixtures/wiring-fictional.json` + `test/wiring-harness-portability.test.js`). `wiring.json` can only ever prove the generator agrees with the shape it was written against; the fictional manifest is as far away as the vocabulary allows — TOML, container `automation.triggers`, FLAT grouping, a different name for every field, three of this framework's events MISSING. It generated its wiring with **zero engine lines added**. ⚠️ **SEEN RED 2026-08-23**: with the field mapping sabotaged (`e[k]` → `e[f]`) the fictional cell FAILS and the Claude Code CONTROL stays GREEN — that asymmetry is the whole reason the fictional harness exists, because on the native manifest the mapping is the identity and measures nothing.
🛑 **THE LAYOUT IS THE VOCABULARY, AND EVERY HOLE IN IT IS A NAMED REFUSAL** — never a silent drop, because a dropped field produces a wiring that RUNS and differs from what was declared. Refused: an unknown `format` (a document in the wrong syntax parses as nothing, with no error and no log) · a field the layout names NO key for · a matcher on a harness declaring `matcherIn: "none"` (dropping it widens a hook from one tool to EVERY tool call) · a `blocks` grouping whose matcher lives elsewhere (a nesting level carrying nothing) · the event declared in TWO places at once (container branch AND `eventKey`) · two of this framework's events spoken with ONE harness name (they would MERGE into one branch, valid and silent). ⚠️ A harness lacking an event is the ORDINARY case: that path is SKIPPED and NAMED on stderr, and `--quiet` silences the count of what was written, NEVER an absence.
🛑 **`write.mode` IS DECLARED, AND `fragment` MUST CARRY ITS REASON.** `splice` = we edit the operator's only copy under the four guards above; `fragment` = we emit the block and they paste it. The splice is admissible as a property of the LAYOUT and never of a product (JSON we can re-read and compare byte for byte · blocks carrying a matcher · a container branching on the event at its second segment) — any harness shaped that way gets the write mode for free, any other gets `fragment` and its written reason, quoted back by the refusal. **A half-written wiring is worse than none.**
🔴 **CODEX: THE FORMAT IS BUILT, THE MANIFEST IS NOT SHIPPED, AND THE REASON IS MEASURED (2026-08-23).** MEASURED in `~/.codex/config.toml`: the hook STRUCTURE is identical to Claude Code's (`[[hooks.SessionStart]]` then `[[hooks.SessionStart.hooks]]`), so only the FORMAT and the ADDRESS differ — and the TOML writer covers it. **An in-place TOML write stays REFUSED**: that file is the operator's only copy and carries ~30 lines of load-bearing COMMENTS (why no model is pinned, why `hooks = true`, the double-injection warning) plus literal strings for Windows paths; no Node TOML library round-trips comments, so a parse-and-rewrite would DESTROY configuration we do not own — hence `write.mode: "fragment"` for every TOML harness, declared as a law of the layout. 🛑 **WHAT ACTUALLY BLOCKS THE CODEX MANIFEST IS NOT THE FORMAT, IT IS ONE NUMBER**: Codex needs `additionalContextLimit` on its two emitters, and `budget-declare-gate` requires it to EQUAL the `--budget N` written in the same command. Writing both by hand in a manifest would put one truth in two places — the 2026-08-22 class, rebuilt inside the file that removes it. Closing it needs a per-consumer DECLARED BUDGET rendered in both writings at once (exactly like the frame coordinates), which the vocabulary does not have yet. Until then the Codex wiring stays hand-written, and that is written here rather than half-shipped.
🛑 **THE TOML WRITER IS A WRITER, NEVER A PARSER, AND THAT IS THE WHOLE SAFETY ARGUMENT.** It only emits values THIS framework produced (POSIX command lines, a URL, integers, event names), so the escaping surface is CLOSED: per the official spec v1.0.0 (read 2026-08-23) a basic string must escape the quotation mark, the backslash and control characters, and bare keys are `A-Za-z0-9_-` only — this writer REFUSES all of those by name instead of guessing an escape. A value carrying one means the input stopped being what we think it is. **Zero new dependency.**
