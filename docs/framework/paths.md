# paths.js — single source of paths

⚠️ EVERY runtime path (config/docs/state) is declared HERE, once. NEVER redo an ad-hoc `path.join(__dirname,'state')` in a hook: `stateDir` was duplicated identically in inject.js AND reset.js — two copies of one truth that diverge silently (the reset would target another folder, with no visible error).
LAZY resolution mandatory (`paths.stateDir()` at call time, never frozen in a const at load) — otherwise the env vars set by the parent at spawn are ignored.
Every env var here (`CTXROUTE_CONFIG_PATH`/`DOCS_DIR`/`STATE_DIR`/`FILEDOCS_DIR`/`SESSIONDOCS_DIR`/`SKILLS_DIR`/`FLEET_HOOKS_DIR`/`TRANSCRIPTS_DIR`) is RESERVED for tests and doctor.js — never a user setting (that is `ctxroute-config.json`).
⚠️ THE FLEET ROOT = `FLEET_SEGMENTS` (2026-08-21), ONE definition with TWO projections that must NEVER be collapsed: `fleetHooksDir()` = ABSOLUTE, anchored at the home, overridable — the address a PROCESS uses to REACH the disk (`fileDocsDir()` hangs beneath it, `skillsDir()` beside it); `fleetHooksLabel()` = RELATIVE, POSIX, home-free, NOT overridable — the address PUBLISHED to a reader in the `[source: …]` tag.
🛑 NEVER emit `fleetHooksDir()` into a tag, a message or a doc: it returns the maintainer's real home (a tmpdir under the test override), and this repository is PUBLIC and treats itself as already public — that is a LEAK, and a test override would rewrite a published contract. The tag is a CONTRACT (an agent reads that exact path to go UPDATE the doc), so a stale prefix breaks the self-repairing loop with nothing going red. Two projections of one truth is the fix; one function is a leak.
⚠️ THE HARNESS ROOTS ARE A REGISTRY, `harnessRoots()` (2026-08-21) — `fleetHooksDir` · `transcriptsDir` (`~/.claude/projects`, the harness TRANSCRIPT corpus, read in bulk by `tools/scope-reach.js`) · `skillsDir`. Declare a root there ONLY if this module owns its accessor: `src/leak-list.js` legitimately assembles `~/.claude/secrets/` and is DELIBERATELY not declared — accusing the truth is how a gate gets disarmed. Frozen at every level (a mutable registry moves a root for everyone, at runtime, including for its own judge).
🛑 NEVER re-assemble ANY of those roots anywhere else — the CLASS is "a harness root rebuilt by hand", NEVER "the hooks root". It existed in FIVE places for the fleet root (three scripts rebuilding `~/.claude/hooks` under three env-var names — `VENDOR_TARGET_DIR`, `CTXROUTE_HOOKS_DIR`, none — plus two hardcoded label prefixes in `source-adapters.js` that nothing read through, which is exactly why they survived), and naming ONE directory left a SIXTH open: `scope-reach.js` still built `~/.claude/projects` from `os.homedir()` with no env var at all. Same shape, same silence, different second segment. `fleet-hooks-path.test.js` = 11 cells: equality per accessor · real-spawn consumption (`vendor-deadline.js`, `scope-reach.js`) · an AST scan of `src/` + `tools/` (perimeter from `git ls-files`, segments from `harnessRoots()`, ONE fabricated offender PER ROOT riding INSIDE the judging scan because `ast-grep` answers `[]` with exit 0 on an unresolved path — a single control would keep passing while a deleted root stopped being policed) · a witness per atom · MENTION-vs-CODE · no `files:`/`ignores:` in the rule · the label AND the registry asserted LITERALLY · no-leak · the two projections tied together.
⚠️ ASK THE LEAK QUESTION FOR EVERY NEW ACCESSOR: does this address ever get EMITTED into a message, a tag or a document? YES ⇒ it needs the relative, non-overridable projection like the fleet root. NO ⇒ one function is enough, and write the reason next to it. `transcriptsDir()` has ONE projection on purpose: it never travels into a document, and the only place it surfaces is a NAMED REFUSAL on an operator's own terminal (not tracked, not published, not injected) — same reason the canary may log an absolute transcript path, and why that log lives under gitignored `state/`.
⚠️ A target that does not exist is a NAMED REFUSAL — `vendor-deadline.js` exits 1 and `scope-reach.js` exits 2, each saying WHICH address it resolved and FROM WHERE — NEVER a silent fallback to a plausible path. Serving the wrong root is the failure this closes, and a wrong transcript root answers `0 collisions`, which reads as good news.
