# foreign-identifier-gate — the IDENTIFIERS of the code are English, and English is the ONLY reference

🔴 **BORN 2026-08-24, OF A HOLE THE PROSE GATE COULD NOT SEE.** Decision ㉒ says the WHOLE project is English. `english-only-gate.test.js` held the PROSE half — scope `docs/framework/` only. The IDENTIFIERS were guarded by NOTHING, and French ones SHIPPED in the published repository. **MEASURED before this gate existed: 888 foreign occurrences over 508 distinct identifiers in 138 files**, out of 17,610 declared identifiers across 217 tracked files.
🛑 **THERE IS NO LIST OF FORBIDDEN WORDS, AND THAT IS THE DESIGN.** A list of FORBIDDEN things is stale the day it is written: it catches only what somebody thought to put in it. `cspell` INVERTS THE BURDEN OF PROOF — nothing is forbidden, what is KNOWN is declared (ordinary English + the house terms of `cspell.json`), so a German `dateipfad` and a French `verrou` are RED for the SAME reason. Fail-closed, and it covers the language nobody anticipated.
🛑 **THE WHOLE GUARANTEE RESTS ON ENGLISH BEING THE ONLY NATURAL-LANGUAGE REFERENCE.** One extra language dictionary opens that entire language while every count keeps passing — a green that lies. Hence `dictionaryFaults`: the config is made to SPEAK (`cspell dictionaries`), confronted with the manifest by EQUALITY, and any dictionary NAMED like a non-English locale is refused by SHAPE (a list of forbidden locales would repeat the very defect). 🛑 Never add a second locale to `language`.
🛑 **A FOREIGN IDENTIFIER IS RENAMED — NEVER ADDED TO `words`.** That is the one way this machinery can be disarmed while looking configured, and it is invisible once done. `words` = product, tool and API names only.
⚠️ **AST, NEVER REGEX, and it is the gate's whole viability.** MEASURED: over the WHOLE TEXT of the tracked files cspell rejects 935 words in 4,690 places (unusable — the comments quote defects on purpose and `english-only-gate.test.js` carries French SENTENCES as fixtures); restricted to DECLARED identifiers, 508 in 888 places. DECLARATIONS only, never USES: a member access is not a place where somebody CHOSE a word.
📐 **DECLARED BLIND SPOT: English contains French LOANWORDS.** 9 of 25 probed words pass — `chemin`, `morceau`, `parc`, `nom`, `sortie`, `dedans`, `sain`, `garde`, `dossier`. Those were renamed BY HAND; the gate does not cover them. A witness must therefore NEVER use a loanword — two of them were, and the ANTI-INERT cell caught it.
📐 **cspell is PINNED ON THE 9.x LINE, MEASURED**: 10.x REFUSES to run on Node 22.15.1 (it demands ≥ 22.18.0 and checks nothing). A gate that cannot run on a contributor's machine gets disarmed.
⚠️ **ANTI-VACUITY IN FOUR LAYERS** (perimeter floor · identifier floor · a CONTROL smuggled into a real scan · a witness per rule atom derived from the `.yml`, plus the reverse). `ast-grep` returns EMPTY JSON with EXIT 0 on a path it cannot resolve, so a misresolved perimeter is INDISTINGUISHABLE from a clean repository.
